# 包赢转盘 · 盟升杯新生组 D题（STM32F103C8T6）

一个由 STM32F103C8T6 驱动的「包赢」抽奖转盘：N20 减速电机带编码器闭环驱动转盘，
EC11 旋转编码器做菜单输入，OLED 显示状态，蜂鸣器做音效反馈。核心卖点是能**精确控制
转盘停在指定区域**（即「包赢」）。

> 学校「盟升杯」新生组 D题参赛作品，**最终以 0 误差获得二等奖**。
> 作者参赛时尚不熟悉 FreeRTOS，工程采用裸机超级循环 + 状态机写法，本仓库作为纪念性
> 保留，**未做 RTOS 重构**。

## 软件架构

裸机（无 RTOS）超级循环 + 状态机：

```
SYS_INIT → MENU_MAIN → { MODE_PAUSE, MODE_SPIN, MODE_TARGET, MODE_SLEEP, MODE_CHEAT }
```

- **软定时基准**：`SysTick` 中断维护 `sec` / `msec` 全局计时，并每 153 个 tick 触发
  `play()` 播放一个蜂鸣器音符（背景音乐）。
- **速度测量**：`speeddetect()` 通过 TIM3 编码器计数的时间差计算转盘转速。
- **闭环调速**：`speedbihuan()` / `speedbihuan2()` 根据实测转速修正 PWM 占空比，
  使转盘稳定在设定转速。
- **显示**：OLED 双缓冲（`OLED_NewFrame` / `OLED_ShowFrame`）。
- 状态机位于 `Core/Src/main.c` 的主 `switch` + 嵌套 `while(1)`。

### 工作模式

| 模式 | 说明 |
|---|---|
| `PAUSE` | 手动调速：设定转速，实时闭环微调并显示当前转速 |
| `SPIN` | 设定转速 + 圈数，转盘按闭环转指定圈数后停止 |
| `TARGET` | 设定圈数 + 目标区域(1–36)，闭环驱动转盘**精确停在目标区域**（「包赢」核心） |
| `SLEEP` | EC11 旋钮随动：转动旋钮，转盘随之正/反转，实时显示位置，用于手动微调定位 |
| `CHEAT` | 旋转到指定区域（演示 / 预设结果用） |

## 版本说明

本仓库（`win final ver`）是**最终参赛版本**。工程中另有一份早期原型 `zzz win`
（位于同级目录，未纳入本仓库），两者演进关系：

| | `zzz win`（初版原型） | `win final ver`（本仓库 · 参赛版） |
|---|---|---|
| 时间 | 2025-10 | 参赛定稿 |
| 电机控制 | 开环（仅设 PWM） | **闭环调速**（`speedbihuan` / `speedbihuan2`） |

## 赛后复盘（作者注 · 已知技术债）

作者赛后从 FreeRTOS / 并发视角回看，以下为当时的设计取舍，保留作为学习记录：

- `Keydetect()` 内含阻塞 `HAL_Delay` 与忙等按键释放，检测按键瞬间电机闭环与显示会短暂冻结。
- `MODE_SPIN` 内层循环无按键检测，**转起来后无法中途急停**。
- 跨中断共享的全局变量（如 `sec` / `msec`）未加 `volatile`，高优化下存在被编译器缓存的风险。
- 圈数统计在窗口内可能重复计数（计数后未更新 `locationstate` 作为离开判定）。
- EC11 增量判断逻辑在多处复制，应抽为单一函数。
- 存在魔法数字（`1386` / `693` / `39` / `13860` / `mubiao` 等），建议以宏定义命名。

以上均为「比赛能跑完」标准下的取舍，并非产品级鲁棒设计；若作为 FreeRTOS 练手项目重构，
可将其拆分为 Motor / UI / Input / Music 等任务并用队列/事件组替代裸全局。
